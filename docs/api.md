# API reference

Base URL (local): `http://localhost:8000`. Interactive Swagger UI is always
available at **`/docs`** (auto-generated by FastAPI). This file is the
hand-written summary.

All decision responses share the **Decision** shape:

```jsonc
{
  "claim_id": "CLM_1A2B3C4D",
  "decision": "APPROVED | REJECTED | PARTIAL | MANUAL_REVIEW",
  "claim_amount": 1500,
  "approved_amount": 1350,
  "rejection_reasons": [],          // e.g. ["PER_CLAIM_EXCEEDED"]
  "rejected_items": [],             // e.g. ["Teeth whitening - cosmetic procedure"]
  "deductions": { "copay": 150 },
  "flags": [],                      // e.g. ["Medical necessity unclear"]
  "network_discount": null,
  "cashless_approved": null,
  "confidence_score": 0.93,
  "notes": "Claim approved within policy limits.",
  "next_steps": "Reimbursement will be processed.",
  "audit_trail": [                  // every rule evaluated, in order
    { "step": "eligibility", "rule": "waiting_period", "passed": true, "detail": "" }
  ]
}
```

## Endpoints

### `POST /api/claims/json`
Submit a **structured** claim (no documents to read). Runs gates → engine → AI
review. This is the deterministic path the test cases use.

Body (`ClaimInput`):
```jsonc
{
  "member_id": "EMP001",
  "member_name": "Rajesh Kumar",
  "treatment_date": "2024-11-01",
  "claim_amount": 1500,
  "hospital": null,                 // optional; a network hospital enables cashless
  "cashless_request": false,        // optional
  "previous_claims_same_day": 0,    // optional; drives the fraud check
  "prescription": {
    "doctor_name": "Dr. Sharma",
    "doctor_reg": "KA/45678/2015",
    "diagnosis": "Viral fever",
    "medicines_prescribed": ["Paracetamol 650mg"],
    "procedures": [], "tests_prescribed": [], "treatment": null
  },
  "bill": { "consultation_fee": 1000, "diagnostic_tests": 500 }
}
```
Returns **Decision** (200).

### `POST /api/claims`  *(multipart/form-data)*
Submit a claim with **document files**. Runs OCR → extraction → engine → AI review.

Form fields: `member_id`, `member_name`, `treatment_date`, `claim_amount`
(required); `hospital`, `cashless_request`, `member_join_date`,
`previous_claims_same_day` (optional). Files: `prescription` (image/PDF),
`bill` (optional). Returns **Decision** (200).

### `GET /api/claims`
List all claims (newest first). Returns a compact array:
```jsonc
[{ "claim_id": "...", "member_name": "...", "decision": "...",
   "claim_amount": 1500, "approved_amount": 1350, "flags": [] }]
```

### `GET /api/claims/{claim_id}`
Returns the full **Decision** for one claim. `404` if not found.

### `POST /api/claims/{claim_id}/review`
The human-in-the-loop action: resolve a claim that's in `MANUAL_REVIEW`.
```jsonc
{ "action": "approve" | "reject", "note": "optional reviewer note" }
```
Returns the updated **Decision** (200). `404` if not found, `409` if the claim
is not awaiting review.

### `GET /api/policy`
Returns the active policy (`policy_terms.json`).

### `PUT /api/policy`
Admin: replace the active policy (used by the admin dashboard). Body is the full
policy JSON. Returns the saved policy (200).

### `GET /health`
Returns `{ "status": "ok" }`.
